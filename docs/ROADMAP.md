# GeneCraft — Development Roadmap

## v1.0.0 — Current Release
**Status: Complete**
- Full simulation engine (genetics, AI, world, food chains)
- 8 biomes with unique mechanics
- 20-node research tree (5 tiers)
- Gene Lab species designer
- 7 disaster types (natural + player-triggered)
- 25 achievements
- 8-chapter campaign + sandbox mode
- JSON save system (5 slots + auto + quicksave)
- Statistics dashboard with population graphs
- Species encyclopedia
- Procedural SFX synthesis

## Long-Term Vision

GeneCraft's ultimate goal is to be the definitive evolution simulation game — 
scientifically grounded, endlessly replayable, and genuinely educational. 
Future expansions will include:

- **University mode**: guided evolution experiments with real biology curriculum links
- **API access**: expose simulation state for external data analysis / research use
- **VR mode**: immersive first-person ecosystem observation
